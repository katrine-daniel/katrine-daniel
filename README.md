## ⭐ Featured project

### [OPERAFlow](https://github.com/katrine-daniel/OPERAFlow) — travel operations platform

One secure backend, database, audit trail and reporting engine for a travel business's day-to-day operations.

- **Booking registry** for online (API / webhook / export) and offline (supplier, direct hotel, email) bookings, with duplicate detection, missing-data checks, margin and reconciliation
- **Daily operations reports**: scheduled, timezone-aware Excel/PDF with delivery history
- **Supplier follow-ups**: Gmail / Microsoft 365 thread tracking with automatic reminders
- **Booking-site test automation** with Playwright journeys against a sandbox
- Role-based access control, audit log, encrypted credentials
- **145 unit/integration tests + 9 browser E2E tests**

**Stack:** NestJS · Next.js 15 · TypeScript · Prisma · PostgreSQL · Tailwind CSS · Playwright · Docker

▶️ **[Interactive demo](https://katrine-daniel.github.io/OPERAFlow/)** — runs in your browser with sample data
